# Todo React Avançado

Aplicação de lista de tarefas construída para praticar Hooks, Context API e memoização no React.

## Tecnologias

- React
- Vite
- `useState`, `useEffect`, `useContext` e `useMemo`
- `React.memo`
- `localStorage`

## Como executar

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite no navegador. Para gerar a versão de produção:

```bash
npm run build
```
